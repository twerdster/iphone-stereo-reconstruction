Stereo matching and depth

Compare two generated rectified images, match a textured patch, and see how disparity relates to depth. The geometry uses Z = f × B / d, with focal length in pixels and baseline in metres.

New educational browser implementation · Synthetic image pair and block matching. It does not run the original iPhone app, estimate camera calibration or validate its manual Q-matrix reconstruction.

The right image is an exact horizontal shift of a deterministic generated texture. A 9 × 9 sum-of-absolute-differences search checks disparities 0–56 px on one scanline. This clean, constant-depth example excludes occlusion, distortion, noise and real stereo calibration; its zero error is not an accuracy benchmark.
